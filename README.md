# Spotify-analysis

##  Caracteristici Analizate
Dashboard-ul explorează următoarele metrici cheie:
* **Popularitate vs. Gen Muzical:** Care sunt genurile care domină clasamentele?
* **Atribute Audio:** Analiza corelației dintre *Energy*, *Danceability* și *Acousticness*.
* **Analiza Temporală:** Cum au evoluat preferințele muzicale de-a lungul anilor/lunilor.
* **Top Artiști & Track-uri:** Identificarea liderilor din setul de date.
